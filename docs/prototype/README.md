# Phalanx Twin prototype

A working daily decision loop — Readiness → Decisions → Decision / Why → Workbench → Twin → Epoch → Provenance —
over a live simulated fleet of 8 aircraft, on the existing screen design, built in one day with four parallel build sessions.
